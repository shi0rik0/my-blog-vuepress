# 推理语言模型真的好吗？

最近有个客户问我用 Qwen3-VL 的普通模型（Qwen3-VL-Instruct）好，还是推理模型（Qwen3-VL-Thinking）好。我不假思索地回答了推理模型好。但是，实际使用过后，我发现这个问题并不是一个非黑即白的问题。

## 什么是推理语言模型

推理语言模型，就是在输出正式回答之前，会先进行一些“思考”的过程，本质上就是生成一些思考过程的 tokens。

传统模型的 token 序列是：

```
[Prompt Tokens] -> [Answer Tokens]
```

而推理模型的 token 序列是：

```
[Prompt Tokens] -> [Thought Tokens] -> [Answer Tokens]
```

当然，传统模型也可以通过在 prompt 里加入“Let's think step by step”之类的指令来引导模型进行思考，但是推理模型在训练的时候有专门针对思考过程进行训练，因此生成的思考过程通常会更好。

## 推理模型的缺点

推理模型能够根据思考过程，生成更好的回答，但是它也存在一些缺点。最大的问题就在于，思考 tokens 会占用模型的上下文长度，从而减少了回答 tokens 的最大长度，并且生成思考 tokens 也会消耗更多的计算资源和时间。

并且在本地部署模型的时候，还会存在一个问题，有些模型（例如 Qwen3-VL）是普通模型和推理模型分开的，所以如果你想要同时使用普通模式和推理模式，就需要部署两个模型实例，占用更多的硬件资源。不过像 Deepseek v3.1 这样的二合一模型就避免了这个问题。
