# 什么是 Generalized Additive Model (GAM)

GAM 本质上是一种推广的线性模型。我们先来回顾一下最基本的线性回归模型：

$$
y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_n x_n
$$

一个简单的推广就是，如果 $y$ 和 $x$ 之间的关系不是线性的，我们可以对 $y$ 进行变换，然后再进行线性回归，也就是

$$
g(y) = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_n x_n
$$

假如这个模型依然不能满足需求，我们还可以考虑对 $x_i$ 进行变换：

$$
g(y) = \beta_0 + \beta_1 f_1(x_1) + \beta_2 f_2(x_2) + ... + \beta_n f_n(x_n)
$$

这样我们就得到了 GAM。

接下来的问题就是选取怎样的 $f_i(x)$，一个经典的选择是使用样条函数 (spline functions)。我们可以选择若干样条函数，然后令 $f_i(x)$ 为这些样条函数的线性组合：

$$
f_i(x) = \sum_{j=1}^{m} \alpha_{ij} s_{ij}(x)
$$

这样我们就可以通过调整 $\alpha_{ij}$ 来拟合数据。

我有一个想法，就是也可以用神经网络来充当 $f_i(x)$。

GAM 的最大优点是可解释性强。因为每个 $f_i(x)$ 都是单变量函数，我们可以很容易地理解每个变量对结果的影响。因此，$f_i(x)$ 的图像也被称作 partial dependence plots。
