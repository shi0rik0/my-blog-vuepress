# 初等数论问题（47）

## 题目

证明：

(1) 存在无穷多的正整数 $n$，使得 $n^2 + 1 \mid n!$；

(2) 存在无穷多的正整数 $n$，使得 $n^2 + 1 \nmid n!$。

## 证明

### (1)

令 $n = 4k^2 + 2k + 1$，其中 $k$ 是大于 $1$ 的整数，则

$n^2 + 1 = 2(2k^2+2k+1)(4k^2+1)$。

显然，$2 < 2k^2+2k+1 < 4k^2+1 < n$，所以 $n^2 + 1 \mid n!$。

### (2)

我们先说明这样的 $n$ 怎么构造。熟知形如 $4k + 1$ 的素数有无穷多个，且对于任意 $4k + 1$ 的素数 $p$，$x^2 \equiv -1 \pmod{p}$ 有解。我们令 $n$ 是满足 $1 \le n < p$ 的解，则有 $p \mid n^2 + 1$ 且 $p \nmid n!$，所以 $n^2 + 1 \nmid n!$。

接下来我们说明这样的 $n$ 有无穷多个。假设满足上面条件的 $n$ 只有有限个 $n_1, n_2, \dots, n_m$，则对于任意 $4k + 1$ 的素数 $p$，$p \mid (n_1^2 + 1)(n_2^2 + 1) \cdots (n_m^2 + 1)$。显然右边是一个有限大的数，其素因子也只有有限多个，矛盾。
