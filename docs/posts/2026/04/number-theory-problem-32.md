# 初等数论问题（32）

## 题目

众所周知，根据费马大定理，当整数 $n > 2$ 时，方程

$$
x^n + y^n = z^n
$$

没有正整数解。

现在我们来考虑一个类似的问题。请证明：当整数 $n > 2$ 时，方程

$$
x^n + y^n = z^{n-1}
$$

存在无穷多组正整数解。

## 证明

可以直接构造出来，令 $k$ 是任意正整数，那么 $x=y=2^{n-2}\cdot k^{n-1}$，$z=2^{n-1}\cdot k^{n}$ 是方程的一个解。

## 注记

构造的思考过程是这样的，首先令 $x=y=2^A$，$z=2^B$，代入方程得到 $2^{nA+1} = 2^{(n-1)B}$，所以 $nA + 1 = (n-1)B$。这里 $A$ 和 $B$ 是关于 $n$ 的函数。注意到当 $n=1$ 的时候，右边为0，所以 $n=1$ 时，$A = -1$，这样就提示我们令 $A = n - 2$，从而得到 $B = n - 1$。至于 $k$ 的部分是类似的。
