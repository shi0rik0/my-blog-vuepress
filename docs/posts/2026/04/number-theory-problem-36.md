# 初等数论问题（36）

## 题目

设 $n$ 是大于 $1$ 的整数，希望找到 $1, 2, \cdots, n$ 的一个排列 $a_1, a_2, \cdots, a_n$，使得对于任意 $1 \le i < n$，$a_i + a_{i+1}$ 和 $|a_i - a_{i+1}|$ 都是合数。证明：这样的排列存在当且仅当 $n \ge 12$。

## 证明

首先证明 $n < 12$ 时不存在这样的排列。显然排列中一定存在相邻两数 $x$ 和 $y$ 是一奇一偶。不妨设 $x > y$，因为 $x - y \le 10$，且 $x - y$ 是奇数，所以只能是 $x - y = 9$，所以 $y$ 只能是 $1$ 或者 $2$，此时 $x + y$ 都是质数。因此 $n < 12$ 时不存在这样的排列。

接下来给出 $n \ge 12$ 时符合条件的数列的构造方法。将 $1, 2, \cdots, n$ 中除了 $3$ 的奇数从小到大排列，记作 $b_1, b_2, \cdots, b_p$。将 $1, 2, \cdots, n$ 中除了 $12$ 的偶数从小到大排列，记作 $c_1, c_2, \cdots, c_q$。

如果 $p$ 是奇数，设 $p = 2k+1$，则将 $\{b_n\}$ 重新排列成：

$$
(b^\prime_1, b^\prime_2, \cdots, b^\prime_{2k+1}) = (b_1, b_3, \cdots, b_{2k+1}, b_2, b_4, \cdots, b_{2k})
$$

如果 $p$ 是偶数，设 $p = 2k$，则将 $\{b_n\}$ 重新排列成：

$$
(b^\prime_1, b^\prime_2, \cdots, b^\prime_{2k}) = (b_1, b_3, \cdots, b_{2k-1}, b_2, b_4, \cdots, b_{2k})
$$

注意到 $b^\prime_i + b^\prime_{i+1}$ 和 $|b^\prime_i - b^\prime_{i+1}|$ 都是大于 $2$ 的偶数，因此都是合数。

按照同样的道理，将 $\{c_n\}$ 重新排列得到 $\{c^\prime_n\}$。最后就可以构造出一个满足条件的排列：

$$
b^\prime_1, b^\prime_2, \cdots, b^\prime_p, 3, 12, c^\prime_1, c^\prime_2, \cdots, c^\prime_q
$$

只需要验证：

1. $(b_i, b_{i+1})$ 满足条件。
2. $(c_i, c_{i+1})$ 满足条件。
3. $(b_p, 3)$ 满足条件。
4. $(3, 12)$ 满足条件。
5. $(12, c_1)$ 满足条件。

这些都是显然的。因此 $n \ge 12$ 时存在这样的排列。
