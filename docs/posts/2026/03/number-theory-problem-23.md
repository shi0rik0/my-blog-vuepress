# 初等数论问题（23）

## 题目

证明：对于任意正整数 $n$，$[1, 2, \ldots, 2n] = [n+1, n+2, \ldots, 2n]$

## 证明

对于任意 $a \in \{1, 2, \ldots, n\}$，存在整数 $k$ 使得

$$
ka > n \\
(k-1)a \le n
$$

则 $ka \le n + a \le 2n$。这说明，总能找到一个 $b \in \{n+1, n+2, \ldots, 2n\}$ 使得 $a \mid b$，这就导致 $a$ 的素因子幂次不会超过 $b$，所以 $[1, 2, \ldots, 2n] = [n+1, n+2, \ldots, 2n]$。
