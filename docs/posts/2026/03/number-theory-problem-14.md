# 初等数论问题（14）

## 题目

求出所有边长为整数，且周长等于面积的三角形。

## 解答

设三角形的边长分别是 $a, b, c$，根据周长等于面积的条件和海伦公式可以得出：

$$
(-a + b + c)(a - b + c)(a + b - c) = 16abc
$$

设 $x = -a + b + c, y = a - b + c, z = a + b - c$，则 $x, y, z$ 都是正整数，并且满足 $xyz = 16(x+y+z)$。

因为 $x + y = 2c$，所以 $x + y$ 是偶数，同理 $y + z$ 和 $z + x$ 也是偶数，所以 $x, y, z$ 要么都是偶数，要么都是奇数。根据原方程可以得到 $16 \mid xyz$，所以只可能 $x, y, z$ 都是偶数。设 $x = 2x', y = 2y', z = 2z'$，则得到

$$
x'y'z' = 4(x' + y' + z')
$$

根据问题（13）的解答，我们可以得到所有的 $(x', y', z')$ 是：

- $(1, 5, 24)$
- $(1, 6, 14)$
- $(1, 8, 9)$
- $(2, 3, 10)$
- $(2, 4, 6)$

从而根据 $a = y' + z', b = x' + z', c = x' + y'$ 可以得到所有的 $\{a, b, c\}$ 是：

- $\{6, 25, 29\}$
- $\{7, 15, 20\}$
- $\{9, 10, 17\}$
- $\{5, 12, 13\}$
- $\{6, 8, 10\}$
