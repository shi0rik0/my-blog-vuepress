# 初等数论问题（24）

## 题目

求所有的具有下列性质的正整数 $n$：对于 $n$ 的任意正因数 $d$，$d+1 \mid n+1$。

## 解答

容易验证 $n=1$ 以及 $n$ 为奇素数的时候满足题意，$n=2$ 不满足题意。

下面用反证法证明 $n$ 是合数的时候不满足题意。设 $n = ab$，其中 $1 < a \le b$，则 $b \ge \sqrt{n}$。$b \mid n$，若 $b+1 \mid n+1$，则有 $b \mid n - b$ 和 $b + 1 \mid n - b$，显然 $(b, b+1) = 1$，所以 $b(b+1) \mid n - b$，这说明 $b(b+1) \le n - b$，但是 $b(b+1) \ge n + \sqrt{n} > n - b$，矛盾。

综上所述，所有满足题意的正整数 $n$ 是 $1$ 以及所有的奇素数。
