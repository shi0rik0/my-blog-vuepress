# 初等数论问题（5）

## 题目

若一个整数可以表示成两个正整数的平方和，我们就说这个整数具有性质甲。

证明：

1. 不存在连续的4个整数，满足它们都具有性质甲。
2. 存在无穷多组连续的3个整数，满足它们都具有性质甲。

## 证明

### 1

整数 $n$ 具有性质甲的必要条件是 $n \not\equiv 3 \pmod{4}$，而连续的4个整数中必然存在一个整数 $n$ 满足 $n \equiv 3 \pmod{4}$，所以不存在连续的4个整数满足它们都具有性质甲。

### 2

考虑三元组 $(100n^2, 100n^2 + 1, 100n^2 + 2)$，其中 $n$ 是正整数。

$100n^2 = (6n)^2 + (8n)^2$，所以 $100n^2$ 具有性质甲。

$100n^2 + 1 = (10n)^2 + 1^2$，所以 $100n^2 + 1$ 具有性质甲。

接下来研究 $100n^2 + 2$，若它具有性质甲，则存在整数 $x, y$ 使得 $100n^2 + 2 = x^2 + y^2$，我们考虑一个特例 $x = y$，则得到方程 $x^2 - 50n^2 = 1$，这是一个 Pell 方程，存在无穷多组整数解 $(x, n)$，所以存在无穷多组连续的3个整数满足它们都具有性质甲。
