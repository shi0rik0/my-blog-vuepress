# 初等数论问题（26）

## 题目

如果一个整系数多项式 $f(x)$ 满足，对于任意的整数 $m, n$，$f(x) \equiv n \pmod{m}$ 都有整数解，那么就称 $f(x)$ 是“好的”。证明：不存在好的二次多项式。

## 证明

显然常数项不影响一个多项式是否是好的，所以我们不妨研究 $f(x) = ax^2 + bx (a \neq 0)$。

引理：假如存在整数 $m, a, b$，满足 $a \not\equiv b \pmod{m}$ 且 $f(a) \equiv f(b) \pmod{m}$，那么显然 $f(x)$ 不是好的。

如果 $|b| \ge 2$，则 $1 \not\equiv -1 \pmod{2b}$，但是 $f(1) \equiv f(-1) \pmod{2b}$，所以 $f(x)$ 不是好的。

如果 $|b| \le 1$，则 $1 \not\equiv 2 \pmod{3a+b}$，但是 $f(1) \equiv f(2) \pmod{3a+b}$，所以 $f(x)$ 不是好的。

综上所述，不存在好的二次多项式。

## 补充

AI 说，好的多项式只有 $f(x) = x + c$ 和 $f(x) = -x + c$，其中 $c$ 是任意整数。下面是 AI 提供的不存在好的二次及以上多项式的证明：

---

### 定理

**不存在次数 $d \ge 2$ 的“好的”整系数多项式。**
（即：若整系数多项式 $f(x)$ 满足“对于任意整数 $m, n$，方程 $f(x) \equiv n \pmod m$ 都有整数解”，则 $f(x)$ 的次数必须为 1，且首项系数为 $\pm 1$。）

### 证明

#### 1. “好”多项式的必要条件

根据定义，若 $f(x)$ 是“好的”，则对于任意正整数 $m$，映射 $\phi_m: \mathbb{Z}_m \to \mathbb{Z}_m$ 定义为 $\phi_m(x) = f(x) \pmod m$ 必须是**满射**（Surjective）。

由于 $\mathbb{Z}_m = \{0, 1, \dots, m-1\}$ 是一个**有限集合**，根据集合论的基本性质，一个从有限集到自身的映射如果是满射，那么它必然也是**单射**（Injective），从而是**双射**（Bijective）。

因此，$f(x)$ 是“好的”必要条件之一是：

> 对于任意正整数 $m$，$f(x)$ 在模 $m$ 下必须是单射。
> 即：若 $f(x_1) \equiv f(x_2) \pmod m$，则必有 $x_1 \equiv x_2 \pmod m$。

#### 2. 导数的性质

设 $f(x)$ 是一个整系数多项式，且次数 $d = \deg(f) \ge 2$。
考虑其形式导数 $f'(x)$。由于 $d \ge 2$，则 $f'(x)$ 是一个次数为 $d-1 \ge 1$ 的非常数整系数多项式。

**引理**：对于任意非常数整系数多项式 $g(x)$，存在素数 $p$ 和整数 $x_0$，使得 $g(x_0) \equiv 0 \pmod p$。
_证明_：因为 $g(x)$ 非常数，当 $|x| \to \infty$ 时 $|g(x)| \to \infty$。必然存在某个整数 $x_0$ 使得 $|g(x_0)| > 1$。取 $g(x_0)$ 的任意一个素因子 $p$，则有 $p \mid g(x_0)$，即 $g(x_0) \equiv 0 \pmod p$。

应用此引理于 $g(x) = f'(x)$，我们可以断定：

> **存在素数 $p$ 和整数 $x_0$，使得 $f'(x_0) \equiv 0 \pmod p$。**
> 即存在整数 $k$ 使得 $f'(x_0) = kp$。

#### 3. 构造模 $p^2$ 下的矛盾

现在我们选取模数 $m = p^2$。我们将考察 $f(x)$ 在 $x_0$ 和 $x_0 + p$ 处的取值。

利用整系数多项式的泰勒展开公式（在整数环上成立）：
$$f(x_0 + h) = f(x_0) + h f'(x_0) + \frac{h^2}{2!} f''(x_0) + \dots + \frac{h^d}{d!} f^{(d)}(x_0)$$
对于整系数多项式，系数 $\frac{f^{(k)}(x)}{k!}$ 本身也是整系数多项式（这是牛顿展开式的性质），因此对于任意整数 $x_0$，各项均为整数。

令 $h = p$，代入上式：
$$f(x_0 + p) = f(x_0) + p f'(x_0) + p^2 \left( \frac{f''(x_0)}{2!} + \dots \right)$$

在模 $p^2$ 的意义下，所有含 $p^2$ 及更高次幂的项均为 0。因此：
$$f(x_0 + p) \equiv f(x_0) + p f'(x_0) \pmod{p^2}$$

根据第 2 步的结论，我们知道 $p \mid f'(x_0)$，即 $f'(x_0)$ 是 $p$ 的倍数。因此 $p \cdot f'(x_0)$ 是 $p^2$ 的倍数，即：
$$p f'(x_0) \equiv 0 \pmod{p^2}$$

从而得到：
$$f(x_0 + p) \equiv f(x_0) \pmod{p^2}$$

#### 4. 验证输入是否不同

我们需要确认在模 $p^2$ 下，输入 $x_0$ 和 $x_0 + p$ 是否是不同的剩余类。
$$ (x_0 + p) - x_0 = p $$
显然，$p$ 不能被 $p^2$ 整除（因为 $p$ 是素数，$p \ge 2$）。
因此：
$$x_0 + p \not\equiv x_0 \pmod{p^2}$$

#### 5. 结论

我们找到了两个不同的输入 $x_0$ 和 $x_0 + p$（模 $p^2$ 下不同），它们映射到了同一个输出（模 $p^2$ 下同余）。
这意味着 $f(x)$ 在模 $m = p^2$ 下**不是单射**。

根据第 1 步的推导，如果在模 $m$ 下不是单射，则必然**不是满射**。
这意味着存在某个整数 $n$，使得方程 $f(x) \equiv n \pmod{p^2}$ 无解。

这与"$f(x)$ 是好的”这一假设（要求对任意 $m, n$ 都有解）相矛盾。

**证毕。**

---

### 补充说明

这个证明不仅否定了二次多项式，也否定了三次、四次以及任何更高次的多项式。
唯一可能成为“好的”多项式只有次数 $d=1$ 的情况，即 $f(x) = ax + b$。
对于 $f(x) = ax + b$ 要成为“好的”，必须满足对于任意 $m$，$ax \equiv n-b \pmod m$ 都有解。这要求 $\gcd(a, m) = 1$ 对任意 $m$ 成立，唯一的可能是 $a = \pm 1$。

因此，**“好的”整系数多项式有且仅有以下形式：**
$$f(x) = x + c \quad \text{或} \quad f(x) = -x + c \quad (c \in \mathbb{Z})$$
