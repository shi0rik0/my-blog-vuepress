# 初等数论问题（19）

## 题目

设 $p, q$ 是素数，$m, n$ 是大于 $1$ 的正整数，解方程：

$$
p^m - q^n = 1
$$

## 解答

由奇偶性分析可知，$p, q$ 是一奇一偶，所以其中必有一个是 $2$。

### 情况1：$p = 2$

此时方程变为 $2^m = q^n + 1$。

假如 $n$ 是偶数，则 $q^n$ 是完全平方数，此时 $2^m \equiv 0 \pmod{4}$，而 $q^n + 1 \not\equiv 0 \pmod{4}$，矛盾。

假如 $n$ 是奇数，则 $q^n + 1 = (q + 1)(q^{n-1} - q^{n-2} + \cdots - q + 1)$，其中 $q^{n-1} - q^{n-2} + \cdots - q + 1$ 是奇数，但是它又必须是 $2$ 的幂，所以只能是 $1$，此时 $q^n + 1 = q + 1$，矛盾。

综上，$p = 2$ 时无解。

### 情况2：$q = 2$

此时方程变为 $2^n = p^m - 1$。

若 $m$ 是奇数，则 $p^m - 1 = (p - 1)(p^{m-1} + p^{m-2} + \cdots + p + 1)$，其中 $p^{m-1} + p^{m-2} + \cdots + p + 1$ 有 $m$ 个项，且每项都是奇数，所以它是大于 $1$ 的奇数，不可能是 $2$ 的幂，矛盾。

若 $m$ 是偶数，设 $m = 2k$，则 $p^m - 1 = (p^k)^2 - 1 = (p^k - 1)(p^k + 1)$，其中 $p^k - 1$ 和 $p^k + 1$ 都是 $2$ 的幂，且差为 $2$。容易得到只能是 $p^k - 1 = 2$ 和 $p^k + 1 = 4$，这样就得到一组解 $(p, m, q, n) = (3, 2, 2, 3)$。

综上所述，方程的唯一解为：$(p, m, q, n) = (3, 2, 2, 3)$。
