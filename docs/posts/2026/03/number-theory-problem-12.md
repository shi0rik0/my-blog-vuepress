# 初等数论问题（12）

## 题目

求下列方程的正整数解：

$$
x! + y! = x^y
$$

## 解答

我们首先证明 $x \le y$，如果 $x > y$，则

$$
x! + y! = y!(1 + \frac{x!}{y!})
$$

设 $1 + \frac{x!}{y!} = A$，则 $(A, x) = 1$ 且 $A \mid x^y$，所以只能有 $A = 1$，矛盾。

因为 $x \le y$，所以 $x! \mid x^y$。若 $x \ge 3$，则因为 $x-1 \mid x^y$，又因为 $(x-1, x) = 1$，所以 $x-1 = 1$，即 $x = 2$，矛盾。所以 $x \le 2$。

当 $x = 1$ 时，$y! + 1 = 1$，无解。

当 $x = 2$ 时，$y! + 2 = 2^y$，容易得到解 $(x, y) = (2, 2), (2, 3)$。

综上所述，方程 $x! + y! = x^y$ 的正整数解为 $(x, y) = (2, 2), (2, 3)$。
