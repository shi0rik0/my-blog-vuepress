# 初等数论问题（15）

## 题目

求所有的素数 $p, q$，使得 $2p - 1, 2q - 1, 2pq - 1$ 都是完全平方数。

## 解答

设 $2p - 1 = a^2, 2q - 1 = b^2, 2pq - 1 = c^2$。

因为 $p \mid c^2 + 1$ 且 $p \mid a^2 + 1$，所以 $p \mid c^2 - a^2 = (c - a)(c + a)$，所以 $p \mid c - a$ 或 $p \mid c + a$。

显然 $p \ne 2$ 且 $a, c$ 都是奇数，所以 $2p \mid c - a$ 或 $2p \mid c + a$，所以 $2p \le c + a$。同理，$2q \le c + b$。

因为 $2p \le c + a$，所以 $c^2 \ge (a^2 - a + 1)^2$，又因为 $c^2 = 2pq - 1= q(a^2 + 1) - 1$，所以 $q \ge \frac{(a^2 - a + 1)^2 + 1}{a^2 + 1} = a^2 - 2a + 2$。同理可得，$p \ge b^2 - 2b + 2$。

将 $p = \frac{a^2 + 1}{2}, q = \frac{b^2 + 1}{2}$ 代入，可以得到 $b^2 \ge 2a^2 - 4a + 3$ 和 $a^2 \ge 2b^2 - 4b + 3$，两式相加后整理配方，就得到：

$$
(a-2)^2 + (b-2)^2 \le 2
$$

容易得到唯一可能的解是 $a = b = 3$，从而必有 $p = q = 5$。验证可知 $2p - 1 = 2q - 1 = 9, 2pq - 1 = 49$ 都是完全平方数，所以 $(p, q) = (5, 5)$ 是唯一的解。
