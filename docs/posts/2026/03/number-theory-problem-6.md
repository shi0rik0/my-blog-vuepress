# 初等数论问题（6）

## 题目

求 $x^5 + y^5 = (x+y)^3$ 的所有整数解。

## 解答

设 $s = x + y$ 和 $p = xy$，则原方程可以改写为：

$$
s(s^4 - 5s^2p + 5p^2) = s^3
$$

如果 $s = 0$，则 $y = -x$，不难验证这时方程成立，所以 $(x, y) = (k, -k)$ 是一个解，其中 $k$ 是任意整数。

若 $s \neq 0$，则可以两边同时除以 $s$，得到：

$$
5p^2 - 5s^2p + (s^4 - s^2) = 0
$$

由于若 $(x, y)$ 是一组解，则 $(-x, -y)$ 也是一组解，所以我们可以只考虑 $s > 0$ 的情况。

将上式视为关于 $p$ 的二次方程，则其判别式为：

$$
\Delta = 5s^2(s^2 + 4)
$$

所以 $s^2 + 4 = 5k^2$，其中 $k$ 是非负整数。

用求根公式得到：

$$
p = \frac{s(s \pm k)}{2}
$$

显然$s^2 \ge 4p$，当 $p = \frac{s(s+k)}{2}$ 时，$s^2 < 4p$，不满足条件，所以 $p = \frac{s(s-k)}{2}$，这时解得 $s \le 2k$，代入 $s^2 + 4 = 5k^2$，得到 $k^2 \le 4$，所以 $k = 0, 1, 2$，逐个代入，得到 $s = 1, 4$。

当 $s = 1$ 时，$p = 0$，所以 $(x, y) = (1, 0)$ 或 $(0, 1)$ 是解。

当 $s = 4$ 时，$p = 4$，所以 $(x, y) = (2, 2)$ 是解。

综上所述，方程 $x^5 + y^5 = (x+y)^3$ 的所有整数解为：

1. $(x, y) = (k, -k)$，其中 $k$ 是任意整数。
2. $(x, y) = (1, 0), (0, 1), (2, 2)$。
3. $(x, y) = (-1, 0), (0, -1), (-2, -2)$。
