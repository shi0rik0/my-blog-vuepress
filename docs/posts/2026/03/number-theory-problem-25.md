# 初等数论问题（25）

## 题目

求所有的正整数 $n$，使得方程 $(x+y+z)^2 = nxyz$ 有正整数解。

## 解答

不妨设 $x \le y \le z$，则 $nxyz = (x+y+z)^2 \le 9z^2$，所以 $nxy \le 9z$。

把原方程看作关于 $z$ 的二次方程，整理得到

$$
z^2 + (2x + 2y - nxy)z + (x+y)^2 = 0
$$

设 $z$ 是方程最小的整数解，则根据韦达定理，另一个解 $z'$ 满足

$$
z + z' = nxy - 2x - 2y \\
zz' = (x+y)^2
$$

根据 $z + z'$ 的等式，我们知道 $z'$ 一定是整数，所以 $z'$ 是方程的另一个整数解。又因为 $z$ 是最小的整数解，所以 $z' \ge z$，因此 $(x+y)^2 = zz' \ge z^2$，所以 $z \le x+y$。

综合前面得到的 $nxy \le 9z$，我们得到 $nxy \le 9(x+y) \le 18y$，所以 $nx \le 18$。

若 $x = 1$，则 $y \le z \le y + 1$，所以 $z = y$ 或 $z = y + 1$。当 $z = y$ 时，

$$
n = \frac{(2y+1)^2}{y^2} = 4 + \frac{4y+1}{y^2}
$$

所以 $y^2 \mid 4y + 1$，所以 $y = 1$，此时 $n = 9$；当 $z = y + 1$ 时，

$$
n = \frac{(2y+2)^2}{y(y+1)} = 4 + \frac{4}{y}
$$

所以 $y \mid 4$，所以 $y = 1, 2, 4$，此时 $n = 5, 6, 8$。

若 $x \ge 2$，则 $n \le 9$。当 $n = 5, 6, 8, 9$ 时，方程都有正整数解，接下来我们只需要研究 $n = 1, 2, 3, 4, 7$ 的情况。

事实上，$n = 1, 2, 3, 4$ 的时候，方程都有解，依次是 $(9, 9, 9), (4, 4, 8), (3, 3, 3), (2, 2, 4)$。

最后只剩下 $n = 7$ 的情况，此时 $x = 2$，所以原方程变为：

$$
(2+y+z)^2 = 14yz
$$

因为 $y \le z \le y + 2$，所以 $z = y, y + 1$ 或 $y + 2$。容易验证无论哪种情况都没有正整数解。

综上所述，所有满足题意的正整数 $n$ 是 $1, 2, 3, 4, 5, 6, 8, 9$。
