# 初等数论问题（1）

## 题目

求以下方程的非负整数解：

$$
a! b! = a! + b! + c!
$$

## 解答

不妨设 $a \leq b$。

若 $a = 0, 1, 2$，显然无解。

若 $a = 3$，则 $5b! = 6 + c!$。mod 5可知 $c < 5$，据此可得到一组解 $(a, b, c) = (3, 3, 4)$。

接下来证明 $a \ge 4$ 时无解。

首先证明 $c > b$，因为若$c \le b$，则：$(a!-1)b! = a! + c! \le 2b!$，则$a! \le 3$，矛盾。

所以 $b!|c!$，又因为$b!|a! + c!$，所以 $b!|a!$，即 $b \le a$，所以$a=b$。

原方程可化为：

$$
a! = \frac{c!}{a!} + 2
$$

mod 3分析可知：

$$
\frac{c!}{a!} \equiv 1 \pmod{3}
$$

所以 $c$ 要么是 $a + 1$，要么是 $a + 2$，接下来分类讨论很容易得到无解。
