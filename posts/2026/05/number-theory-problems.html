初等数论问题集

  1. σ(n) 表示正整数 n 的正约数之和。证明：σ(n) 是奇数当且仅当 n 是完全平方数或 2n 是完全平方数。

设 $n = 2^k m$，其中 $m$ 是奇数，利用 $\sigma(n)$ 的积性。

  1. 证明：对于任意正整数 n，存在 n 个连续的合数。

考虑 $A + 2, A + 3, \ldots, A + n + 1$，我们希望有 $2 \mid A + 2$，$3 \mid A + 3$，$\ldots$，$n + 1 \mid A + n + 1$，那么 $A$ 可以取什么？

  1. 设整数 n>1，τ(n) 表示 n 的正约数的个数。证明：2τ((n−1)!)≥τ(n!)。

记 $a_p = v_p((n-1)!)$，$b_p = v_p(n)$，则 τ(n!)τ((n−1)!)=∏p∣nap+bp+1ap+1=∏p∣n(1+bpap+1)

$$ a_p = \left\lfloor \frac{n-1}{p} \right\rfloor + \left\lfloor \frac{n-1}{p^2} \right\rfloor + \cdots \ge \left\lfloor \frac{n-1}{p} \right\rfloor \ge \frac{n}{p} - 1 $$

$pb_p \le p^{b_p}$

考虑将乘积两两合并，也就是证明 $$ \left(1 + \frac{X}{n}\right)\left(1 + \frac{Y}{n}\right) \le \left(1 + \frac{XY}{n}\right) $$

  1. 设 p 是大于 3 的素数，证明：p2≡1(mod24)。

  2. 设 p 是素数，n 是正整数，求所有的数组 (p,n)，使得 p2−p+1=n3。

$p(p-1) = (n-1)(n^2 + n + 1)$

若 $p \mid n-1$，用大小估计法。

若 $p \mid n^2 + n + 1$，设 $n^2 + n + 1 = kp$。能否得到一个只含 $k, n$ 的关于 $n$ 的二次方程？

当 $k$ 较大时，判别式必然夹在两个完全平方数之间。

考虑 $(k^2-3)^2$ 和 $(k^2-2)^2$。

$(p, n) = (19, 7)$

  1. 对于任意正整数 n，证明：n∣φ(2n−1)，其中 φ(n) 是欧拉函数。

考虑阶的性质：若 $k$ 是 mod $m$ 的阶，则 $k \mid \varphi(m)$。

  1. 设 p 是素数，且 p≥7。证明：存在三个模 p 互不相同的整数 a,b,c，使得 ab≡bc≡ca(modp)。

利用费马小定理来构造。

令 $a = 4$，$b = \frac{p-1}{2}$，$c = p-1$。

  1. 设整数列 {an} 满足，对于任意 n，都有 an>1，且 (2an−1)an+1 是完全平方数。证明：该数列中不存在相等的两项。

先证明若 $k > 1$，则 $a_k$ 不是完全平方数。用 $P(n)$ 表示 $n$ 的幂次是奇数的最大素因子。若 $xy$ 是完全平方数，则 $P(x) = P(y)$。能否证明 $P(a_n) < P(a_{n+1})$？

设 $P(a_n) = p$，则一定存在素数 $q > p$，满足 $v_q(2^p - 1)$ 是奇数（这里要用到阶）。然后用升幂定理分析 $v_q(2^{a_n} - 1)$。

  1. 设 p 是素数，且 p≥5，证明：42p∣3p−2p−1。

  2. 证明：存在无穷多正整数 n，使得 [2n] 是完全平方数。

即 $k^2 \le \sqrt{2}n < k^2 + 1$。

我们希望 $\frac{n}{k^2} \approx \sqrt{2}$。考虑佩尔方程 $x^2 - 2y^2 = \pm 1$，注意到该方程的解满足 $\frac{x}{y} \approx \sqrt{2}$。

令 $n = xy$，$k = x$。

  1. 求所有的正整数 a,b，使得 2a!+2b! 是完全立方数。

对于任意正整数 $n$，$2^n + 1$ 不是完全立方数。

$(a, b) = (2, 2)$。

  1. a,b 是大于 1 的整数，b2∣a3，a−1∣b−1。证明：a=b。

设 $a^3 = b^2 k$，然后 mod $(a-1)$ 分析。

  1. 证明方程 x2+y2−z2=xyz−2 没有整数解。

看作关于 $z$ 的二次方程，分析判别式。

$n^2 = 0,1,4,9 \pmod{16}$。

若 $(\frac{-4}{p}) = (\frac{-8}{p}) = 1$，则 $p \equiv 1 \pmod{8}$。

  1. 求所有正整数 a,b，使得 (a2+b)(a+b2) 是 2 的幂。

设 $a^2 + b = 2^x$，$a + b^2 = 2^y$。两式相减之后，因式分解并分析奇偶性。

$(a, b) = (1, 1)$。

  1. 求所有的正整数 n，使得 2n+n∣8n+n。

  1. 求所有的正整数 n，使得 3n+n2+3 是完全平方数。

首先分析 $n$ 的奇偶性。

设 $n = 2m$，则 $3^n = (3^m)^2$。当 $m$ 较大时，$3^n + n^2 + 3$ 必然夹在两个完全平方数之间。

$n = 2, 4$。
